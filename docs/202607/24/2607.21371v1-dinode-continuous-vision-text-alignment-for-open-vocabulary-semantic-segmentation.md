## 摘要
开放词汇语义分割（OVSS）利用文本语义对超出预定义类别的对象进行分割。虽然自监督模型DINOv3提供了强大的结构化视觉表示，但其缺乏原生的文本对齐能力，阻碍了其直接应用于OVSS。为弥合这一差距，我们提出了DINOde，一个基于常微分方程（ODE）的框架，该框架将CLIP文本嵌入与DINO视觉流形进行连续对齐。我们的方法采用两个互补组件：（i）语义文本流（STF），通过连续ODE轨迹将文本嵌入向DINO流形演化；（ii）全局上下文流（GCF），逐步优化DINO的CLS标记所携带的整体图像表示。为在此演化过程中保持特征空间的超球面几何结构，我们进一步引入了速度切向投影，将学习到的速度场约束在切空间内。通过将对齐建模为连续轨迹，DINOde避免了离散MLP投影固有的流形纠缠，并产生了更鲁棒的跨模态对齐。大量实验表明，DINOde持续优于现有方法，并在多个OVSS基准测试中实现了最先进的性能。代码可在https://github.com/yoon307/DINOde获取。

## Abstract
Open-vocabulary semantic segmentation (OVSS) leverages textual semantics to segment objects beyond predefined categories. While the self-supervised model DINOv3 provides strong structured visual representations, its lack of native textual alignment hinders its direct application to OVSS. To bridge this gap, we propose DINOde, an ODE-based framework that continuously aligns CLIP text embeddings with the DINO visual manifold. Our approach employs two complementary components: (i) Semantic Text Flow (STF), which evolves text embeddings toward the DINO manifold through a continuous ODE trajectory, and (ii) Global Context Flow (GCF), which progressively refines the holistic image representation carried by DINO's CLS token. To preserve the hyperspherical geometry of the feature space during this evolution, we further introduce Velocity Tangent Projection, which constrains the learned velocity field to the tangent space. By modeling alignment as a continuous trajectory, DINOde avoids the manifold entanglement inherent in discrete MLP projections and yields more robust cross-modal alignment. Extensive experiments demonstrate that DINOde consistently outperforms existing methods and achieves state-of-the-art performance across multiple OVSS benchmarks. The code is available at https://github.com/yoon307/DINOde.

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：开放词汇语义分割（OVSS）需要将视觉表示与文本语义对齐，以便分割未见过的类别。自监督视觉模型（如DINOv3）具有优越的结构化空间特征，但缺乏与文本的对齐能力；而对比学习模型（如CLIP）虽能对齐视觉与文本，但其视觉编码器偏向全局表示，空间细节不足。
- **现有方法局限**：现有方案如 `dino.txt` 需要从头训练文本编码器，计算成本高；`Talk2DINO` 通过非线性映射（MLP）对齐两个空间，但离散的单步投影破坏了流形的拓扑结构（如“猫”和“狗”之间的语义邻近性），导致语义纠缠（Semantic Entanglement）。
- **研究动机**：提出一个连续的、保流形的对齐框架，避免离散映射的流形扭曲，实现更鲁棒的跨模态对齐。

### 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：将视觉-文本对齐建模为**常微分方程（ODE）**的连续轨迹，从CLIP文本嵌入逐步演化到DINO视觉流形，保持几何结构。
- **关键组件**：
  - **语义文本流（Semantic Text Flow, STF）**：将文本嵌入 $z_{\text{text}}$ 线性投影到DINO特征维度作为初始状态 $z_0$，通过神经网络 $v_\theta$ 学习速度场，在超球面上连续演化：
    $$ \frac{dz_t}{dt} = v_\theta(z_t, t), \quad z_1 = z_0 + \int_0^1 v_\theta(z_t, t)\, dt $$
    使用**速度切向投影（VTP）** 将速度约束到切空间：$\tilde{v}_\theta = v_\theta - \langle v_\theta, z_t\rangle z_t$，以保持特征归一化和超球几何。
  - **全局上下文流（Global Context Flow, GCF）**：对DINO的CLS标记 $z_{\text{img}}^{\text{cls}}$ 进行类似ODE演化，得到全局表示 $\hat{z}_{\text{img}}^{\text{cls}}$，捕获整体图像语义。
  - **损失函数**：采用CLIP式对称对比损失（NCE loss），将池化后的patch特征与CLS特征拼接为全局图像表示，与对齐后的文本表示进行对比学习。
- **推理**：对任意类别文本，通过STF生成对齐的文本嵌入 $\hat{z}_{\text{text}}$，与DINO的patch token计算余弦相似度，得到分割图。支持后处理PAMR细化边界。
